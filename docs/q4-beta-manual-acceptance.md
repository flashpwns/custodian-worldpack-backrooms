# Clear-Q4 beta manual acceptance

This checklist is for a real tester using the packaged application. Do not
mark the result from automated tests. Record one result only: `PASS`,
`CONDITIONAL PASS`, or `FAIL`.

## First run

- [ ] ASYNC boot sequence is visible and can be skipped.
- [ ] Title/access surface identifies Yellow Beast as an unofficial project.
- [ ] A fresh world can be created offline.
- [ ] BRIEFING explains assignment, team, equipment, reporting, and next step.
- [ ] STAGING_AND_EQUIPMENT shows required and optional gear without silently equipping it.
- [ ] THRESHOLD_ROOM is understandable and does not render the Complex early.
- [ ] Crossing the threshold is an explicit, time-consuming player action.
- [ ] First Standard radio check is available only when radio capability exists.

## Field interaction

- [ ] ACTION remains the dominant input lane.
- [ ] LOCAL addresses only a legitimately nearby teammate.
- [ ] STANDARD transmits only through legitimate radio capability.
- [ ] Team status uses coarse, observer-safe categories.
- [ ] Loadout shows holder, condition, and availability without hidden state.
- [ ] Map/layout software distinguishes current, prior, reported, and unresolved information.
- [ ] Evidence uses a real capture record or a finished offline fallback.

## Run conclusion and continuity

- [ ] Return requires physical route/threshold progress; completion does not teleport anyone.
- [ ] Personnel and equipment accountability preserves missing, dead, separated, and abandoned states.
- [ ] Mission review is derived from recorded history.
- [ ] ADVANCE OPERATIONS preserves the world and prepares a legitimate next assignment.
- [ ] Early return, objective failure, separation/contact loss, abandonment, and succession remain distinct where reached.

## Persistence and replayability

- [ ] Save/reload and app restart preserve phase, mission, controlled identity, equipment, map, and evidence.
- [ ] Repeated expeditions show structural mission/site/staff variation grounded in history.
- [ ] Callback personnel remain singular and dead personnel do not return.
- [ ] Quiet/subtle trajectories remain possible.
- [ ] Dialogue responds to identity, role, knowledge, and shared history without leaking hidden state.
- [ ] Tester genuinely wants to continue playing.
