# Async: Clear-Q4

Clear-Q4 is an offline-capable expedition presented through the YB-27 freeform loop. The shared phase model provides briefing, staging, facility transit, Threshold, field operation, return, and debrief context without becoming world truth. Equipment, radio messages, evidence, and return outcomes remain existing canonical/runtime state. Guidance is optional, diegetic, and never completes actions for the player; reporting remains distinct from observation and objective history.
