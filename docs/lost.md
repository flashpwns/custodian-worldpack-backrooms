# Lost

Lost is a bounded roguelike run over the shared world history: a seed determines a minimal loadout and whether a bounded region contains an escape opportunity. The player has only visible topology, run notes, and carried resources. Failure strands the run and leaves eligible carried items as persistent location-local remnants; escape is never fabricated for a no-exit run.
# Lost sensory exploration

Lost is an offline, scene-and-input-first observer experience. It exposes only immediate perception, carried objects, and legitimately remembered landmarks or physical markers. Formal topology, institutional terminology, risk meters, and hidden causes remain absent. Physical objects persist across revisits and modes, but private memory and motives never transfer.
