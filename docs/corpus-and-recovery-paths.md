# Corpus roots and recovery-path boundaries

## Corpus inventory

`corpus/roots.json` records the supplied YouTube playlists as external discovery roots. `corpus/videos.json` deduplicates accessible entries by YouTube video ID while preserving every playlist membership and position. Hidden unavailable entries are retained as root-level unavailable placeholders because YouTube did not expose their metadata.

Inventory is not review: every registered video remains `unclassified-video`, project-scope `unresolved`, directly unchecked, unreviewed, and has no canon authority. Titles, durations, and locators are metadata only. No media or transcript is stored. Future review promotes a source through the existing intake lifecycle; it never promotes a playlist entry automatically.

## Transitions and recovery

A transition record distinguishes visible access context from origin, destination, route knowledge, repeatability, return, and stability. A visible controlled apparatus does not by itself prove a completed crossing, destination, safe route, mechanism, or future availability. A recovered record is evidence lifecycle data; it cannot supply a recovery route merely because an object or media exists later.

Observer-local route knowledge is distinct from objective topology, memory, belief, and institutional assertion. The Threshold Baseline return is marked pack-original and scenario-optional: it exercises Custodian persistence and communication without becoming Kane Pixels canon.

## Worked examples

1. A playlist root is enumerated into an unreviewed video record. A later milestone may directly review that official upload, create a verified locator, extract a claim, and only then seek canon admission.
2. First Contact's verified apparatus locator produces a source-local controlled-access observation. It leaves destination and return unresolved. The separate baseline fixture records a deterministic return route as a pack-authored convenience, not a universal exit mechanic.

## Reviewer checklist

- Treat playlist membership as discovery only.
- Preserve unavailable metadata gaps; never invent titles or dates.
- Use video ID as the corpus identity and preserve duplicate playlist memberships.
- Require a verified primary locator before an authoritative transition claim.
- Keep a return observation separate from permanent bidirectionality and mechanism.
- Do not infer recovery route, global map, universal exit, or observer knowledge from institutional context.

Run `npm run corpus-report` and `npm run transition-report` for deterministic summaries.
