# Quality of life

YB-30 Pass 4 organizes the current observer-safe desktop projection; it does
not read raw world history, create memory, or change canonical state.

“What do I know?” is mode-specific. Clear-Q4 summarizes the operational
picture, Beck lists matters and received reports, Nullzone groups personal
questions and evidence, and Lost only offers sparse nearby memory, carrying,
and immediate condition. Recent history is bounded and uses the same
mode-appropriate material, never raw event logs.

Search filters only the already-rendered Beck and Nullzone recap material.
Pins, recap-panel state, and unfinished natural-language drafts are local
presentation metadata keyed by world and observer mode. They do not affect
simulation, thread significance, probability, or another world’s UI.

Existing session resume remains authoritative and does not advance time. A
small “Last time” line is derived from current safe history; stale request
state is never resumed. Accepted turns continue to autosave. Export makes a
portable copy while leaving the library world intact; deleting names the target
world and its sessions before confirmation. Renaming changes only library
metadata, never world identity.

`?` opens the recap and `Escape` closes it when focus is not in a text control.
The only retry offered after an application failure is **Refresh view**, which
retrieves the current safe projection and never resubmits a canonical action.
Pass 5 owns accessibility and player-preference expansion.

Pass 5 keeps QoL metadata separate while making it operable at all supported
text sizes, high contrast, reduced motion, keyboard focus, and assistive-tech
status paths. Pins retain their presentation-only meaning.

Pass 6’s long-session fixture exercises 150 mixed presentation interactions.
History stays bounded, and neither pending request tokens nor panel state are
restored with a session.
