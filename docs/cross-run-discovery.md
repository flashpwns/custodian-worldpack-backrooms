# Cross-run discovery

The deterministic `persistent-history-trial` fixture proves the intended boundary: a Clear-Q4 procedural run materializes and reports a region; a later compatible Clear-Q4 run reuses that region without inheriting the first observer's discovery state. A synthetic Lost-compatible run can leave a labelled pack-original field-bag remnant in the same region; a later field run may recover it only at its location.

The shared object is objective world history. Institutional route labels require a submitted/archived report. Lost and civilian profiles do not receive those records automatically. Future Beck's Desk can consume archived expeditions and topology; future Nullzone can use its separate personal archive.
