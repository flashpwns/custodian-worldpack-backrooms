## Institutional boundary

Standard receives only delivered/acknowledged messages, missed declared expectations, returned records, and closure reconciliation. The delayed message does not update Standard before delivery. Remote injury and route/equipment truth remain absent until a delivered report or return establishes them. Institutional decisions resolve through the shared scheduled-event/communications architecture, and every transition retains public explanation, private rationale, time, and provenance.

## Logistics transaction boundary

Every item/container operation validates a cloned state for actor proximity, current custody, capacity, category compatibility, condition, accessibility, target availability, route/hazard constraints, mission phase, and bounded nesting. Only a fully valid proposal replaces canonical logistics state. Failed operations cannot partially consume, transfer, duplicate, or strand contents.
