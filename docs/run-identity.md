# YB-32 Pass 1: Run identity

Run identity is a derived description of legitimate starting conditions and
subsequent history, not a canonical field, plot track, difficulty setting, or
character archetype. `tools/run-identity.js` composes the existing observer-safe
startup projection with the seed-driven procedural realization: bounded space
family, qualitative lighting/surface, local landmark/object vocabulary, and
unknown frontier count. It also records profile-declared knowledge, resources,
permissions, and a small set of explicit initial questions.

The strongest variation remains canon-supported local environment material.
Mundane operational roles and resources remain conservative procedural glue;
their labels do not become named characters or capability modifiers. Lost's
existing seed-driven loadout/return condition remains bounded and explicit.
No rarity tiers, affixes, destiny labels, hidden plot selections, stat changes,
or canonical lore are introduced.

The descriptor is exposed through the ordinary observer-safe run status and is
reconstructed on save/resume. Identical seed/profile/scenario inputs produce an
identical descriptor; different seeds may vary only in the admitted surfaces.
`npm run run-identity-report` and `tests/y32-run-identity.test.js` cover these
guarantees.
