# YB-32 aggregate replayability closure

`npm run y32-replayability-report` is the Pass 6 aggregate check. It combines the deterministic run-identity and v2 environment surfaces with the 150-turn canonical convergence fixture, derived story threads, consequence echoes, unfinished business, save/reload, four observer profiles, and canon-runtime gravity.

The report checks that same seeds reproduce the same identity and local realization, multiple seeds vary only across admitted environment surfaces, new worlds do not share state, and observer views contain no raw identifiers, hidden fate, taxonomy, or meta-progression. It also confirms that repeated derived reads do not append events, dead characters remain dead, one physical object remains one identity, and reload rebuilds derived views.

All output is a report of existing canonical/runtime material. It does not create a run, callback, quest, objective, thread cache, or gameplay progression. YB-33 starts only after this report, the existing regression suite, desktop validation, and both packaging targets are green.
