# Reactive in-universe UI

YB-30 Pass 2 keeps the Pass-1 navigation shell and treats the renderer as a
pure, observer-safe presentation layer. It reads the existing desktop
projection and never writes canonical history, remembers extra facts, or
infers connections between private mode projections.

Clear-Q4 places the current scene and natural-language action ahead of an
operational field brief. Objectives, radio, team condition, equipment, and
phase-sensitive guidance are contextual rather than competing dashboards.
Beck uses a desk: reports and calls lead, decisions sit on the desk, and people
and work in progress stay in the margin. Nullzone is a personal notebook with
observations, comparison material, and only personally available carrying and
route context. Lost reduces the surface to sensation, immediate surroundings,
what is carried, and optional memory; it contains no institutional framing,
objective system, map, taxonomy, or thread log.

The natural-language action form is the first game control in every mode.
Structured controls remain a deterministic offline fallback. Renderer-only
state such as a collapsed detail disclosure is browser presentation state; it
is neither serialized nor promoted into world truth.

`npm run reactive-ui-report` records the Pass-2 guardrails. Its zero-valued
invariants cover canonical mutation, hidden or private-state leakage, opaque
identifiers and implementation language, Lost institutional chrome,
provider-internal metadata, unsupported threat claims, and natural-language
input priority.

Pass 3 adds no world knowledge to this layer. Submitted, resolving, and result
feedback belongs only to an application request. A reply is rendered only if it
still belongs to the active world and mode; navigation invalidates pending
renderer requests. Motion is a short scene-result settle transition, not an
indication of danger, discovery, character fate, provider latency, or hidden
phenomena.

Pass 4 reuses those safe projections for recap, bounded history, and local
filtering. Recap panels, pins, and drafts are presentation metadata keyed to a
world and mode; they cannot cross observers or add a world fact. The Lost recap
is intentionally sparse and does not become a map or investigation board.
