# Scenario Profiles

A Scenario Profile is a declarative player/session configuration layered over one Yellow Beast objective model. It configures starting observer knowledge, permissions, resources, compatible scenario classes, objectives, failure possibilities, and UI labels. It cannot change canon, physics, anomaly mechanisms, or objective history.

Conceptual UX: **Select World: Yellow Beast → Select Mode: ASYNC Command / Field Researcher / Local Anomaly / Lost → Select Scenario: compatible choices only → Start Run**.

Institutional records remain records, not omniscience or objective truth. The Lost profile has no universal-exit assumption. Developer fixtures remain outside player-facing profile choices; the four current content entries are scaffolds, not finished playable scenarios.
