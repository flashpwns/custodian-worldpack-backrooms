# Institutional simulation

`yellow-beast-becks-desk@v2` progresses only through accepted logical-time
advances. It is deterministic, event-backed materialization in the shared
world; it is neither wall-clock work nor a second ASYNC world.

Institutional processes cover expeditions, recovery, research, and bounded
infrastructure. Teams act from their scoped routes, reports, equipment, and
observations. A field observation becomes institutional knowledge only after
its report is delivered and explicitly reviewed.

Research is evidence-gated: a reviewed report supplies recorded input
provenance, then an approved process consumes bounded budget and logical time.
Its result is an institutional operational recommendation/unlock, never a new
world fact, hidden topology, or an entity/hazard change.

Infrastructure candidates require an institutionally known v2 region and an
already discovered location. Completing a project appends a `region.mutated`
object event, so a survey marker is a persistent physical object in the shared
world. Nullzone and Lost can observe that object locally, but do not receive
ASYNC ownership, project, or report knowledge.

`yellow-beast-institution-projection@v1` is the UI-safe contract for a future
Beck desktop surface. It exposes logical time, teams, personnel, resources,
communications, incidents, recovery, eligible/active/completed research,
infrastructure, known-complex summaries, and a derived actionable task queue.
It excludes hidden topology, private civilian/Lost knowledge, undelivered
observations, entity/hazard internals, generator state, and raw physical-world
object identities. The task queue is derived from reports, incidents, research
candidates, and proposed infrastructure; it is not persistent truth.

These processes leave gameplay hooks for later objectives, evidence value,
recovery, preparation, research follow-ups, resource tradeoffs, and persistent
cross-mode consequences without implementing a strategy-game economy.
