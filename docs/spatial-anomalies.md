# Controlled environmental anomalies and spatial discontinuities

YB-8 records a source-local observed condition, not a mechanism. An anomaly record identifies the observed setting, marking or visible boundary state, interaction records, visible result, persistence, repeatability, and uncertainty. It cannot establish a portal, a destination, dimensional physics, or a global rule.

## Boundary, interaction, and causality

A blue tape perimeter is an observer marking. It is not proof of an exact physical boundary. Interactions are separate records: an object can cease to be visible without the pack asserting where it went, whether it was destroyed, or whether it can be recovered. A later event may be `followed-by` an earlier event, but that sequence is never an automatically causal relation.

`observed-once`, `repeated-during-same-observation`, and `repeatability-unknown` remain distinct. Repeated tests in one source do not create a reusable material law. Local discontinuities never create a global Complex map or a shared destination.

## Terminology discipline

Yellow Beast uses the pack-neutral term *anomaly* for a bounded observed condition. Community shorthand such as *noclip*, *portal*, and *Null Zone* is reference-only in this record set; none is an authoritative mechanism or classification.

## Worked example

1. The official *Backrooms - Found Footage #2* upload is registered with directly checked early-sequence locators.
2. `ff2-marked-floor-garage-view` represents only the source-local recorded view.
3. `ff2-marked-floor-surface-discontinuity` records the marked local region and visible interaction result.
4. Separate loose-material, baseball, and measuring-tape interactions preserve what was tested without asserting a destination.
5. The narrow admitted claim describes the visible result; `ff2-destination-and-mechanism-remain-unresolved` prohibits using it as physics or destination truth.
6. A future scenario can reference the observation only as a fixed, source-local fixture; dynamic, random, or executable anomaly behavior is outside YB-8.

## Reviewer checklist

- Directly verify the finished-source locator and keep any media outside the repository.
- Preserve marked or approximate boundaries as approximate.
- Separate an interaction result from the object's destination and from a mechanism.
- Record temporal sequence without inferring causation.
- Reject universal, shared-destination, and community-shorthand mechanics.
- Keep any scenario convenience explicit and non-authoritative.

Run `npm run anomaly-report` for the deterministic summary.
