# YB-32 Pass 4: Unfinished business

Unfinished business is a derived view of observer-visible history, not a new objective system. It recognizes only unresolved conditions already supported by canonical events or the observer’s existing safe knowledge: unrecovered objects, unanswered reports, incomplete communications, personnel absences, unexplained observations, institutional disagreement, and personal questions or hypotheses.

The same view is delivered through native mode language: Clear-Q4 calls it operational follow-up, Beck calls it pending matters, Nullzone keeps it among questions and personal evidence, and Lost exposes only implicit memory/continuity cues. There are no quest IDs, objective markers, mystery IDs, scripted beats, forced endings, or automatic callbacks. Ordinary simulation actions are the only way a condition can change.

`tools/consequence-echoes.js` derives the view from canonical history and current observer-safe domains. It is bounded, non-mutating, observer-filtered, save/reload reconstructible, and never exposes raw identities, taxonomy, hidden fate, or causes. `npm run unfinished-business-report` exercises the deterministic 150-turn fixture, repeated reads, and save/reload.
