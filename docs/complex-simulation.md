# Complex simulation expansion

YB-22 expands the shared procedural environment without turning generated content into Backrooms canon. The source record, generator rule, region trait, generated space, local environment, persistent mutation, and observer knowledge are separate layers.

## Regions and topology

Each persistent region has a stable identity, seed lineage, generator version, materialized graph, and authority provenance. V2 regions use bounded architectural families, coherent regional tendencies, frontier policies, branches, bounded hubs, loops, and reconvergence. A loop reconnects existing objective nodes rather than duplicating a location. Region transitions preserve both region identities and do not upgrade their parent.

## Landmarks, environment, and objects

V2 materializes mundane navigational landmarks such as fixture arrangements, ceiling-tile patterns, furniture clusters, and utility features. Landmarks are persistent physical records with rule provenance. Observers discover them through local perception and receive profile-safe aliases rather than internal IDs.

Lighting, ceiling condition, and material wear are qualitative, local, deterministic states. Regional gradients are bounded tendencies only. Object rules place a small set of mundane classes—chairs, tables, debris, and containers—with constrained clusters and stable identities. They are not a loot system and do not imply supernatural meaning.

## Mutations and revisits

World-significant changes, including adding or removing an object and persistent local state changes, append `region.mutated` events in `yellow-beast-world-history@v1`. The baseline region plus ordered events reconstructs current state idempotently. Revisit preserves topology, landmarks, baseline environment, and object identities except where an explicit event changed them.

## Shared world, scoped knowledge

Clear-Q4, Nullzone Exposure, Lost, and Beck's Desk use the same objective region. Clear-Q4 can report a discovered summary to ASYNC. Nullzone and Lost discover the physical region independently and retain private route knowledge. Beck sees only archived institutional summaries; it does not receive civilian archives, Lost notes, hidden region traits, or unreported local mutations.

Generated features are pack-original bounded synthesis unless a narrow source-local analog authorizes the rule. They never promote themselves to Kane Pixels canon claims.
