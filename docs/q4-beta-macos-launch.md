# macOS limited-beta launch notes

Yellow Beast is an unofficial, unsigned, arm64-only macOS build. It is not
notarized. macOS Gatekeeper may require manual approval.

1. Open the downloaded ZIP and move `Yellow Beast.app` to a local folder such
   as Applications.
2. If macOS blocks the first launch, open **System Settings → Privacy &
   Security**, review the blocked application notice, and choose **Open
   Anyway** after confirming the source.
3. Alternatively, Control-click the app in Finder, choose **Open**, then
   confirm **Open** in the prompt.

Do not disable Gatekeeper globally and do not remove quarantine silently. The
current package is arm64-only, unsigned, and not notarized.
